## 📌 Overview

StoreMaster is a fully functional store management dashboard that allows users to manage products, process sales, and track profits with an intuitive interface.

- **Problem solved:** Provides a complete solution for small business owners to manage inventory and sales without complex software
- **Built for:** Store owners, inventory managers, and developers learning JavaScript
- **What makes it different:** Pure JavaScript implementation with interactive dashboard, real-time calculations, and zero dependencies

## 🏗️ Architecture & Technical Decisions

### Project Structure
```
StoreMaster/
├── index.html # Main dashboard
├── style.css # All styles in one file
├── script.js # Complete JavaScript logic
└── README.md # Project documentation
```


### Key Technical Decisions

**Why pure JavaScript without frameworks?**
> Using vanilla JavaScript demonstrates core programming concepts and keeps the project lightweight. It's perfect for learning and easy to maintain.

**Why single-file approach for CSS/JS?**
> For a dashboard of this size, keeping everything in single files makes development faster and deployment simpler. The code is organized with clear comments.

**Object-Oriented Approach**
> Used constructor functions for Product and Sale models, making the code modular and scalable.

**Real-time Dashboard Updates**
> Statistics cards show current data that updates as products and sales change.

## 🚧 Challenges & How I Solved Them

### Challenge 1: Maintaining data consistency
**Problem:** When selling products, inventory needs to update automatically  
**Solution:** Created interconnected Product and Sale models that update in real-time  
**Result:** Stock levels always accurate, no manual updates needed

### Challenge 2: User-friendly interface for complex operations
**Problem:** Store operations need to be simple for non-technical users  
**Solution:** Designed quick-action cards with clear icons and simple prompts  
**Result:** Anyone can use the system with minimal training

### Challenge 3: Real-time profit calculations
**Problem:** Profits need to be calculated across different time periods  
**Solution:** Built flexible reporting functions that filter by date and product  
**Result:** Instant access to any profit report needed
